I currently work as a senior software engineer at [SAP Cloud Infrastructure](https://github.com/sap-cloud-infrastructure) on the [ApeiroRA](https://apeirora.eu/) project. In this project we build an open source cloud stack for Europe which will be donated to the [NeoNephos Foundation](https://neonephos.org/) under the governance of [Linux Foundation Europe](https://linuxfoundation.eu/). Inside this stack, I work at the [CobaltCore](https://github.com/cobaltcore-dev) layer which connects [OpenStack](https://www.openstack.org/) and the Kubernetes-backed [IronCore](https://github.com/ironcore-dev) layer which forms our Bare-Metal Operating System.

Specifically, I work on scheduling and inventory components inside this stack. My main project is [Cortex](https://github.com/cobaltcore-dev/cortex) which provides smart workload distribution and inventory management. But I also contribute to our AI inference service [Thalamus](https://github.com/cobaltcore-dev/thalamus) and various other components like the [VM Operator](https://github.com/cobaltcore-dev/vm-operator), hypervisor [Operator](https://github.com/cobaltcore-dev/openstack-hypervisor-operator) and [Agent](https://github.com/cobaltcore-dev/kvm-node-agent), as well as [HA](https://github.com/cobaltcore-dev/kvm-ha-service).

Before I worked at SAP, I built PrioBike, a [Flutter app](https://github.com/priobike/priobike-flutter-app) that provides a green wave to cyclists. I worked heavily on a [probabilistic traffic light prediction service in Golang](https://github.com/priobike/priobike-predictor), a [machine-learning traffic light matching service written in Python](https://github.com/priobike/priobike-sg-selector), and a [GraphHopper-based highly accurate bike routing](https://github.com/priobike/priobike-graphhopper-drn). Much of this has also been published at [international conferences](https://scholar.google.com/citations?user=JuH3KLAAAAAJ&hl=de&oi=sra) as part of my PhD.

Before PrioBike, I made money developing apps for iOS and worked on interesting free-time projects like a [Golang-based PoS Blockchain](https://github.com/peerbridge/peerbridge), and was heavily into computer graphics and machine learning building [3Dify](https://github.com/PhilippMatthes/3dify-ios) and [neural greenscreen](https://github.com/PhilippMatthes/neural-greenscreen).

From time to time, you may see new projects pop up on my GitHub, such as [finance dashboard for income/expense analysis](https://github.com/PhilippMatthes/finance-dashboard), a [spotify quiz like HITSTER](https://github.com/PhilippMatthes/spotify-quiz), or even Strudel [music](https://github.com/PhilippMatthes/strudel) and [tools](https://github.com/PhilippMatthes/strudel-tuner). Most of the time, it is because I want to learn new stuff or have fun exploring new topics.
